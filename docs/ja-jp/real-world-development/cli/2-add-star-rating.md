Copilot CLI をインストールし、会話を試しました。次は、プロジェクトに最初の変更を加えます。変更は小さくしましょう。ゲームのデータには星評価がすでにありますが、ホームページのゲームカードにはまだ表示されていません。エージェントに評価を表示させ、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次のことを行います。

- 機能ブランチで、目的を絞った Copilot の会話を開始します。
- エージェントにプロジェクトの小さな変更を依頼します。
- `/diff` で変更をレビューします。
- 転送されたブラウザーでアプリを実行し、変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲームの詳細ページにはすでに表示されています。しかし、ホームページのゲームカードにはタイトル、カテゴリ、パブリッシャー、説明しか表示されていません。ウォームアップとして、エージェントに各カードで既存の評価を表示させます。これは最初のセッションにぴったりな、小さく独立した変更です。

## 会話の構成

**会話**は、Copilot CLI を使ってタスクに取り組む場所です。Copilot app とは異なり、通常の CLI 会話では、専用の worktree ではなく、ターミナルで現在チェックアウトされているリポジトリと Git ブランチを使用します。保存した会話を後で再開できますが、ファイルとブランチはディスク上の通常の Git 状態のままです。

会話では、プロンプトとエージェントの応答、ファイルを調査・編集する際のエージェントのツール操作、`/diff` で確認できる変更の 3 つを確認できます。

## 会話を始めて変更を依頼する

機能の実装を始めるため、新しい会話を開始しましょう。

1. Codespace に戻ります。
2. ターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>\`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>\`</kbd> (Windows/Linux) を押します。
3. まだ起動していない場合は、次のコマンドで Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. スラッシュコマンド `/new` を入力して <kbd>Enter</kbd> を押し、新しいセッションを開始します。
5. 次のプロンプトで変更を依頼します。

   ```plaintext
   ゲーム一覧ページの各ゲームカードに、5 段階評価の starRating を表示してください。評価が null の場合は "No rating yet" と表示してください。カードのレイアウトはそのままにし、テストを追加して、関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調べ、ゲームの詳細を表示するファイルを見つけて、必要なコードを作成します。これで Copilot CLI を使った新機能の追加は完了です。

## 差分をレビューする

小さな変更でも、AI が生成した変更はすべてマージ前にレビューします。Copilot CLI で変更を確認しましょう。

1. `/diff` を入力して、変更されたファイルをすべて確認します。
2. ゲームカードに数値の評価がある場合はそれが表示され、`starRating` が `null` の場合は `No rating yet` と表示されることを確認します。
3. テストで両方の状態がカバーされていることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. レビューが完了したら、<kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> すべての生成 AI ツールと同様に、Copilot は決定論的ではありません。そのため、実際のコードはここに示す例と異なる場合があります。完全に同じ実装を期待するのではなく、動作を確認してください。

## 変更を確認する

コードを読んだだけで動くと決めつけず、Copilot に Web サイトを起動してもらい、Codespaces で転送されたブラウザーから更新された UI を確認しましょう。

1. Copilot にアプリの起動を依頼します。

   ```plaintext
   ブラウザーで星評価の変更を確認できるよう、アプリを起動してください。URL を教えて、サーバーは実行したままにしてください。
   ```

2. Codespaces でポート `4321` が利用可能と表示されたら、**Open in Browser** を選択します。
3. ゲームカードに 5 段階の評価が表示されることを確認します。
4. Copilot に戻り、起動したサーバーを停止するよう依頼します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初のプルリクエストを作成してマージする

機能を実装できました。次は、プロジェクトにコードをマージするためのプルリクエスト (PR) を作成します。

1. デフォルトエージェントに変更をコミットするよう依頼します。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージでコミットしてください。
   ```

2. `/pr create` を入力します。Copilot CLI は PR の作成時に既存のコミットをプッシュし、PR の URL を表示します。
3. Copilot CLI に表示された URL を、<kbd>Command</kbd> (Mac) または <kbd>Ctrl</kbd> (Windows/Linux) を押しながら選択して、PR を開きます。
4. 変更されたファイルとチェックをレビューします。
5. 問題がなければ、**Merge pull request** を選択し、マージを確認します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```
