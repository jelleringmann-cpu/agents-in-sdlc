通过贴近实际的场景、完整应用和共享待办列表，探索 GitHub Copilot 在整个软件开发生命周期中的用法。你将迭代规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

设想你是 Tailspin Toys 的新开发人员。这是一家为桌游提供众筹服务、带有开发者主题的虚构公司。团队的待办事项已作为 GitHub 议题创建，你可以直接开始处理。其中既有筛选和分页等功能任务，也有无障碍和编码规范等质量改进。

## 选择工作环境

GitHub Copilot 可在不同的工作环境中协助你。选择最符合你开发习惯的环境。每个工作坊都有各自的设置步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge，以及实用的斜杠命令。

### [GitHub Copilot app][app]

并行运行智能体会话、切换会话模式、协作使用画布，并通过桌面应用管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步智能体、引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
